# nnamdiokorafor.com — mirror (RETIRED)

This repository no longer mirrors the site. The live design references its assets with
root-absolute paths (`/_next/...`, `/assets/...`), which cannot resolve at a GitHub Pages
subpath, so a copy here would render without CSS, JS or images.

`index.html` is a forwarding stub to <https://nnamdiokorafor.com/>.

Source of truth: the private workspace (`website/`, built by `build.sh`) deployed to Cloudflare
Pages.
